# Word Finder &middot; [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)  [![Privacy Policy](https://img.shields.io/badge/GDPR-Privacy_Policy-blue.svg)](https://github.com/dayuun1/word_finder/blob/Lab1(standart)/PRIVACY_POLICY.md)

A "Word Finder" game built with React. Find various words in a grid of different sizes vertically, horizontally, and diagonally.

---

## Features

- **Three Grid Sizes**: 5×5, 10×10, and 15×15.
- **Language Support**: Toggle between different languages.
- **Stats & Timer**: Track your performance and time.
- **Theming**: Support for Light and Dark themes.

---

## Installation

```bash
# 1. Clone the repository
git clone [https://github.com/dayuun1/word_finder.git](https://github.com/dayuun1/word_finder.git)

# 2. Navigate to the project folder
cd word_finder

# 3. Install dependencies
npm install

# 4. Start the server
npm run devn

# 4. Запустіть
npm run dev
```

## Commands

```bash
npm run dev
```
