Word Finder

Гра "Пошук слів" (Word Search) на React. Знаходження різноманітних слів в полі різного розміру по вертикалі, горизонталі та діагоналі.

---

## Можливості

- Поле трьох розмірів: 5×5, 10×10, 15×15
- Можливість зміни мови
- Статистика та таймер

---

## Встановлення

```bash
# 1. Клонуйте репозиторій
git clone https://github.com/your-username/word-finder.gitкту

# 3. Встановіть залежності
npm install

# 4. Запустіть
npm run dev
```

---

## Команди

```bash
npm run dev
```
