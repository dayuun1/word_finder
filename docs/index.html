Word Finder · 

A "Word Finder" game built with React. Find various words in a grid of different sizes vertically, horizontally, and diagonally.

Features

  • Three Grid Sizes: 5×5, 10×10, and 15×15.
  • Language Support: Toggle between different languages.
  • Stats & Timer: Track your performance and time.
  • Theming: Support for Light and Dark themes.

Installation

# 1. Clone the repository
git clone [https://github.com/dayuun1/word_finder.git](https://github.com/dayuun1/word_finder.git)

# 2. Navigate to the project folder
cd word_finder

# 3. Install dependencies
npm install

# 4. Start the server
npm run devn

# 4. Запустіть
npm run dev

Commands

npm run dev
